# WildConnect Backend

Centralized wildlife tourism platform backend API.

## Setup Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Configure Environment:**
   Copy the example environment template and configure your secrets:
   ```bash
   cp .env.example .env
   ```

3. **Run Development Server:**
   ```bash
   npm run dev
   ```

4. **Build the Application:**
   ```bash
   npm run build
   ```

5. **Start Production Server:**
   ```bash
   npm run start
   ```

## Available Scripts

- `npm run dev`: Starts the development server with live reload enabled using Nodemon and tsx.
- `npm run build`: Compiles the TypeScript source files in `src/` to JavaScript files in `dist/`.
- `npm run start`: Starts the compiled production application.
- `npm run test`: Placeholder script for running test suites.
