## 3. Brand Identity

**Global Color Palette (Hex-Based Design Tokens)**

The official theme uses centralized design tokens to create a natural, wildlife-friendly, and modern aesthetic without looking like camouflage.

**Primary Colors:**
- **Deep Forest** (`--color-primary`: `#1F4D3A`): Used for primary buttons, main navigation, active states, and brand elements.
- **Pine / Primary Dark** (`--color-primary-dark`: `#16382B`): Used for hover states, dark sections, strong emphasis, and footer backgrounds.
- **Secondary Moss** (`--color-secondary`: `#6B8E5A`): Used for secondary buttons, tags, supporting UI, and natural highlights.

**Accent Colors:**
- **Warm Amber** (`--color-accent`: `#D99A3D`): Used *sparingly* for CTAs needing extra attention, selected states, and small wildlife/adventure-related visual accents.

**Backgrounds & Surfaces:**
- **Ivory** (`--color-background`: `#F7F5EF`): Main page backgrounds, large content areas.
- **White** (`--color-surface`: `#FFFFFF`): Cards, modals, forms, dashboards.

**Text & Neutrals:**
- **Charcoal** (`--color-text-primary`: `#26332D`): Headings, body text, important labels.
- **Sage Gray** (`--color-text-muted`: `#6F7B73`): Secondary text, descriptions, metadata, helper text.
- **Border** (`--color-border`: `#DCE2DC`): Card borders, input borders, dividers, tables.

**Semantic Colors:**
- **Success** (`--color-success`: `#3F7D4A`): Successful actions, confirmed bookings.
- **Error** (`--color-error`: `#B94A48`): Errors, failed actions, destructive warnings.

## 15. Color Usage

**Approximate Visual Balance:**
- 60% — Ivory / White backgrounds
- 25% — Forest / Green elements
- 10% — Secondary natural colors
- 5%  — Amber accent

**Primary Actions** (`--color-primary`, `--color-primary-dark`)
Use Deep Forest for main buttons and primary links. Use Pine for hover states.

**Secondary Actions** (`--color-secondary`)
Use Secondary Moss for tags, secondary buttons, and supporting UI.

**Backgrounds** (`--color-background`, `--color-surface`)
Use Ivory for page backgrounds and main content areas. Use White for cards and modals.

**Borders** (`--color-border`)
Use Border color for dividers, tables, and inputs.

**Highlights & Accents** (`--color-accent`)
Use Warm Amber sparingly. Do not use for every button. Reserve for selected states, important highlights, or CTAs needing extra attention.

**Links**
Use Deep Forest (`--color-primary`).

**Error Messages**
Use Error (`--color-error`: `#B94A48`) for validation, failed actions, and destructive warnings.

**Success Messages**
Use Success (`--color-success`: `#3F7D4A`) for positive status and confirmed bookings.
